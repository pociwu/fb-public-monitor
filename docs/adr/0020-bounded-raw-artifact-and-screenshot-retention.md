# 原始批次與瀏覽器截圖採有限保存

成功匯入的壓縮 Apify 原始 JSON 在捕獲完成後保存 90 天，失敗或爭議資料保留至結案；批次帳本、原始檔 SHA-256、存取觀察摘要及其證據雜湊永久保存。一般 Chromium 畫面每帳號保留最新十張；風控事件每次只保存一張最寬 1600px、約 1 MB 內的 WebP，保存 180 個 24 小時，總量不超過 `500 MiB = 524,288,000 bytes`。清理時先移除逾期檔，再依 `captured_at, id` 刪除已結案的最舊事件。永久內容與最高解析度媒體不清除，每日清理只處理本服務到期原始資料、截圖、暫存及無引用檔案。
