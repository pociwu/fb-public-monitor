# 回溯批次自動續跑並保留最低公平性

每批成功提交游標後立即建立下一批，服務重啟時從持久狀態續接，不再依賴 6–8 小時巡檢或人工操作。標準 ID `100027675104517` 確認公開後五分鐘內必須建立或更新唯一 capture epoch；只有契約已通過、帳號未凍結、取得預算保留且 scheduler 正常時，才在現有付費 run 安全結束後派送第一批，否則進入 `awaiting_contract`、`paused_manual` 或 `paused_budget`，絕不繞過保護。服務離線期間的事件於啟動 reconcile 補排。特殊帳號轉公開的貼文與多媒體優先，其次是其他未完成回溯、一般巡檢與留言；Apify 同時只執行一個付費批次，且每四個最高優先批次至少放行一個到期的一般工作。
