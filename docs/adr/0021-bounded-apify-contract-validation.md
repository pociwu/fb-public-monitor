# Apify 內容 Actor 上線前以最多 0.20 美元驗證契約

正式回溯前以最新匿名、身分一致的強證據已確認公開，且由操作人確認預期至少有 25 篇可見非置頂貼文的測試帳號執行四個受限批次：十篇第一頁、使用其游標的十篇第二頁、重播相同第二頁游標，以及使用已知 ID／時間停止邊界的最多兩篇增量測試。歷史公開證據不得蓋過後續的強私人證據。排除置頂重複後，第一與第二批不得重疊，第二頁重播必須得到相同身分集合與輸出游標，增量測試不得付費取回已知內容，`SUMMARY` 與明確 terminal 語義必須可解析。

這一份是 **posts cursor contract**：通過只代表上述貼文分頁、重播與邊界行為已驗證，不代表相簿、影片、公開照片頁、大頭照／封面歷史或留言完整性已驗證。各媒體與留言 surface 必須另有獨立契約與 coverage terminal 證據。

操作人每次明確核准一輪全域 grant，本輪跨測試帳號與候選 Actor 的實際計費加模糊保留合計不得超過 0.20 美元。主要候選失敗後，備援只可使用同輪已知剩餘；若餘額不足，必須確認無模糊 run、結束本輪並另行明確核准新輪，不自動追加支出。任一條件失敗即停用該 provider fingerprint 與用途，不開始正式回溯或增量巡檢。

Web 上會建立 grant、契約測試或正式回溯工作的 POST 只接受同源 `Origin`/`Referer`。兩者都缺少時視為操作人在主機上使用 CLI/curl，保留相容；只要提供任一個不同源值即拒絕，不建立付費工作。
